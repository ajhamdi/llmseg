# LLMSeg project page

Static site (Bulma, no build step). Preview with `python -m http.server` in this folder.
Deploy by publishing this folder (for example with GitHub Pages).

- The results table and the cIoU chart are rendered from `RESULTS` in `static/js/index.js`.
- The qualitative comparisons are rendered from `COMPARISONS` in the same file; images are in `static/assets/`.
- The arXiv button and the BibTeX in `index.html` point to arXiv:2610.29409.
